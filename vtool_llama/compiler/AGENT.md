# CharacterCompiler — vtool_llama

Compilador del system prompt del personaje. Ensambla las ~27 capas cognitivas (DNA, estado, alma, mods, psicología) en el prompt final que recibe el LLM.

## AGENT

Si el usuario pide algo relacionado con el system prompt del personaje, capas del prompt, YAMLs de personaje, resolución de conflictos entre capas, o modificación de cómo se ensambla el prompt, **LEER PRIMERO** `DETA.md` antes de responder o modificar cualquier archivo.
